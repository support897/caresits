I would create a weighted matching engine.
The first version can be transparent and rule-based. AI can help interpret profile descriptions, but it should not independently determine whether someone is qualified or safe.

* = compatibility score.
* = importance of each matching criterion.
* = how well the two profiles match that criterion, from 0 to 1.
